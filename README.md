# C++ User Data Manager 💻

Консольна програма мовою C++ для демонстрації роботи зі структурами (`struct`) та об'єднаннями (`union`). Розроблена як лабораторна робота для дослідження структур даних та динамічного управління пам'яттю.

## ⚙️ Основний функціонал
- **Створення записів:** Динамічне додавання нових користувачів (`addUser`) зі збереженням їхніх даних у масив або список структур `User`.
- **Читання даних:** Виведення повного списку зареєстрованих користувачів у консоль (`outp`).
- **Інтерактивне меню:** Зручна навігація за допомогою консольного інтерфейсу з кольоровим форматуванням тексту (ANSI escape codes).
- **Модульність:** Винесення логіки роботи з даними в окремий заголовковий файл `utilit.h`.
